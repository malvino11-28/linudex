O debloat do dispositivo vai ser realizado com UAD-ng (Universal-Android-Debloater-next-generation) a partir do windows 10

Depois, os aplicativos no dispositivo foram deletados manualmente.

Para garantir mais RAM, foi colocado 8gb de memória virtual no dispostivo
